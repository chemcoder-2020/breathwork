How fast can it go? The web API only switches the motor on/off, so the "rate" is 1 / (tap + gap). Taps stay readable down to ~40 ms; gaps below ~30 ms merge into one continuous buzz. That caps clean discrete pulses at roughly 8–10 per second — faster than that and it stops feeling like pulses at all. The native app runs 2–3 Hz for comparison.
